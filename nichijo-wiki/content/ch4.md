# 終章　天上界

```概要
位階: 天上界
目標: エンドの外縁へ渡り、最後の災厄エンダーガーディアンを鎮める
到達点: 八つの大災厄をすべて鎮め、「大災厄の旅人」になる
```

## 挑むもの

| 相手・場所 | どこ | メモ |
| --- | --- | --- |
| エンダーガーディアン | 崩壊した砦（エンドの外縁） | [[ボイドアイ]] で探す。砦のエンダーゴーレムを倒して進む（ゴーレムは [[虚空のコア]] を落とす）。→ [[守護者の籠手]] |
| エンドの城の亡霊 | エンドの城 | 中ボス |
| エンドの灯台、孤独なエンドの船 | エンドの外縁 | 探索先 |

## 作るもの

| 作るもの | 材料・方法 |
| --- | --- |
| [[終龍の魔法書]] | エンダードラゴンの [[龍の革]] |
| エンチャント台 Lv90〜100 | ドラゴンブレスを注入したエンドの本棚、ドラゴンの頭から竜宿るエンドの本棚 → [エンチャント台](enchanting.md) |
| ミシック装備 | 最高のレアリティ。解体すると最上の素材 → [装備と称号](gear.md) |

## 冒険手帳

- [ ] エンドの外縁に渡った
- [ ] エンダーガーディアンを倒した
- [ ] エンチャント台をLv100まで上げた
- [ ] 八つの大災厄をすべて倒した（→「大災厄の旅人」）
