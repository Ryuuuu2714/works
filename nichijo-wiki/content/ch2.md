# 第二章　炎の向こうへ

```概要
位階: 進撃
目標: ネザーと海の素材で魔術を一段上げ、地下の「不死者の帝王」に挑む
次へ進む条件: レア以上の装備一式＋ウィザーを倒す
```

## ネザーで集めるもの

| 素材 | 入手 | 使い道 |
| --- | --- | --- |
| [[ホグリンの革]] | ホグリン | 見習いの魔法書、上位の魔導書 |
| [[煉獄のマニュアル]] | ブレイズがまれに持っている魔導書。灰になる前に倒すのがコツ | 魔術入りの魔導書 |
| [[燃え殻のエッセンス]] | アーマーパイル（鎧の山）を壊すと起きる「古代の騎士」 | 大釜・地図の材料 |
| 古代の残骸 | ネザーの地中 | ネザライト。第三章の「アイ」にも使う |

### 城塞

原初の焔の担ぎ手《タイロス》の残響が待つ場所。

- [[巻かれた地図]]（城塞）が道を教えてくれる。[[燃え殻のエッセンス]]＋[[古代の知識の断片]]＋紙
- 宝物庫に [[パイリウムインゴット]]（[[焔結晶の杖]] の材料）
- 城塞は古代の魔術結界に守られている。[[守護のアミュレット]] が結界から身を守るらしい（入手方法は未確認。分かったら書き足してください）

そのほかのネザーの遺構：ピグリンの砦、ネザーの砦、骸骨の塔など
