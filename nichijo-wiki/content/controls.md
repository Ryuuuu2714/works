# 操作と便利な機能

## 困ったら、まずこれ

| 機能 | 使い方 |
| --- | --- |
| JEI（画面右のアイテム一覧） | インベントリを開いて、アイテムにカーソルを合わせ「R」で作り方、「U」で使い道 |
| キー設定の検索 | 設定 →「操作設定」の検索欄に「呪文」「リュック」などと入れると、MODのキーが見つかる。重なって競合してるキーは赤くなってるので都合のいいところに再設定してください。おすすめは下の「おすすめのキー設定」 |
| このWikiの図鑑 | アイテム名を入れると、MOD・作り方・入手先がだいたい分かるはず |

## この鯖ならではの操作

- **Ctrl＋T**：世界の位階（ワールドレベル）の画面を開く。とても大事。この世界のメインコンテンツにがっつり。というかストーリー（自己解釈）の本筋。[全体の流れ](flow.md) を参照。
- **魔導書**：装備画面の「魔導書のスロット」に入れて使う。唱えるキー配置は「操作設定」で「呪文」と検索。
- **転移石（ウェイストーン）**：右クリックで「触れる」（帰り道として覚える）。もう一度右クリックすると、飛べる先の一覧が出る。自分で置いた石には名前を付けられる。
- **レシピの選び直し**：材料が同じでできあがりが違うレシピは、作業台の横に出るボタンで選べる。
- **リュック**：背負ったリュックはキーで開ける。キー配置は「操作設定」で「リュック」と検索。
- **戦い方**：剣や斧などは、振るタイミングと連撃で動きが変わり、片手武器・両手武器の概念がある。
- **満腹度**：食べ物にカーソルを合わせると、回復する量が分かり、満腹度ゲージに隠し満腹度も表示されている。

## おすすめのキー設定

MODが多いので、初期設定のままだとキーがいくつか重なってる。特に V は「呪文を唱える」と Cataclysm の防具の技が重なってて、呪文を唱えるとバックステップまで出てしまう。下のとおりに直せば、遊んでて困る重なりはなくなる。

考え方はこの3つ。
- よく使う呪文のキー（V・R）は、MODの初期設定のまま。変えるキーを少なくするため。
- Cataclysm の防具の技は、左下の **Z・X・C** にまとめる。左から **足・胴・頭**（体の下から順）。
- 使わないキーは「未割り当て」にして、赤い表示を消す。

> 【ヒント】操作設定の検索欄に、下の表の「操作設定での名前」を入れると出てくる。検索欄の横のボタンを「競合を表示」にすると、重なってるキーだけが並ぶ。キーを消すときは、キーのボタンを押してから Esc。

### 変えるキー

| 操作設定での名前 | 初期 | おすすめ | ひとこと |
| --- | --- | --- | --- |
| Cataclysmのブーツアビリティ | V | Z | カーシウムブーツのバックステップ。足なので一番左 |
| Cataclysmのチェストプレートアビリティ | Y | X | ブルーム・ストーン・ポールドロンのアメジスト。胴なので真ん中 |
| Cataclysmのアビリティ | V | 未割り当て | 今はこれを使う装備がない |
| インベントリ連動機能を実行 | C | 未割り当て | リュックのキー。ヘルメットの技（C）と重なるので |
| ホットバーの保存・ホットバーの読み込み | C・X | 未割り当て | クリエイティブでしか使わない |
| 1つ目の追加機能のON/OFF・2つ目の追加機能のON/OFF | Alt＋Z・Alt＋X | 未割り当て | リュックのキー。使ってる人はそのままでもいいけど、押すと Z・X の技も一緒に出る |
| ツールチップのタブを切り替える・ツールチップをGIFで記録する | G・H | 未割り当て | 今は使わないキー |

### そのままでいいキー（よく使うもの）

| 操作設定での名前 | キー | ひとこと |
| --- | --- | --- |
| 選択した呪文を唱える | V | 一番よく使う |
| スペルホイールを開く | R | 押してる間ホイールが出て、呪文を選べる |
| スペルバーの呪文選択 | 左Alt | 押しながらマウスホイールを回すと、呪文が切り替わる |
| アイテムをオフハンドと交換 | F | |
| Cataclysmのヘルメットアビリティ | C | 頭なので Z・X・C の一番右 |
| リュックを開く | B | Backpack の B |
| Curiosインベントリの開閉 | G | 魔導書や指輪を着ける装備画面。インベントリの中のボタンからも開ける |
| ピンを打つ | ボタン5（マウスの親指の前のボタン） | 見てる場所に印を出して、みんなに知らせる |
| ワールドレベル選択を開く | Ctrl＋T | 世界の位階の画面 |
| プレイヤーの死亡履歴を開く | U | 死んだ場所と、持ってた物が分かる |
| メインハンドの武器の技を使う | 未割り当て | 固有武器の技は右クリックで出るので、なくていい |

### マウスにサイドボタンがない人

「ピンを打つ」を **G** に変えて、「Curiosインベントリの開閉」を未割り当てにする。装備画面はインベントリの中のボタンから開ける。

### サイドボタンがある人は、お好みで

**ボタン4（親指の後ろのボタン）** に「クイックキャストスロット01」を入れると、魔導書の1つ目の呪文を、ホイールで選び直さずにすぐ唱えられる。

### 赤くても放っておいていいもの

- JEI のキー（R・U・A・クリックなど）：インベントリなどの画面の中でだけ効くので、遊んでる最中のキーとはぶつからない。
- Shift：しゃがむ・Jade の詳しい表示・装備の比較が重なってるけど、同時に効いても困らない。
- Ctrl と組み合わせたキー（Ctrl＋T など）：T などと赤くなるけど、ちゃんと別々に効く。
- キーパッドのキー（Jade・支援者の翼など）：テンキーのないノートでは押せないけど、使わなくて困らない。

## 転移石の名前の付け方

自分で置いた石には、みんなが分かる名前を付けるとまあ親切。  
「北の鉱山」「沈没した都市の前」「酒場（雪原）」とか？  
とはいえ都市名とかは固有名詞あったほうが良い気もするし、特にルールでガチガチにしてもオモンないし、割と好きにしてOK！
