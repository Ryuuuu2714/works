# 序章　漂着

```概要
位階: 安全地帯
目標: 拠点をつくり、最初の称号付き装備を集める
次へ進む条件: 防具4部位と武器をすべて称号付きにする
```

この位階では侵略者が現れません。落ち着いて準備できる唯一の時期です。

## まずやること

1. **寝床と拠点**：木と石の道具、ベッド。家具（椅子・机・棚など）も作れる
2. **転移石に触れる**：村や野原に [[転移石]]（ウェイストーン）が建っている。見つけたら必ず右クリック
3. **酒場を探す**：森・平原・砂漠・雪原などにある。地図屋からエメラルドで「クエスト地図」を買える
4. **リュックを作る**：[[革のリュック]]（革・糸・チェスト）。あとから大きくしたり、機能を足したりできる

> 【ヒント】遠くへ飛ぶには [[ワープダスト]] が要ります。エンダーパールとアメジストの欠片を貯めておきましょう。

> 【メモ】みんなの拠点の転移石は、東野が「グローバル」に設定します。グローバルの転移石へは無料で帰れます。

## 魔術の入口

魔術は、まず [[スクロール]]（巻物）として見つかります。そのまま使うと1回で消えるので、魔導書に書き込んで使います。

```順番
[[スクロール]] を拾う → [[銘刻台]] で魔導書に書き込む → 何度でも唱えられる
```

| 作るもの | 材料 | 用途 |
| --- | --- | --- |
| [[銘刻台]] | 本・木のハーフブロック・木の柵 | 魔導書にスクロールを書き込む |
| [[鉄縛の書]] | 鎖・革・紙 | 最初の魔導書 |
| [[長老の杖]] | 木のシャベル・鉄インゴット・[[秘術のエッセンス]] | 最初の杖 |

魔導書は、装備画面の「魔導書のスロット」に入れて使います。

[[秘術のエッセンス]] は、魔術の道具づくりにほぼ必ず使う素材です。宝箱（ダンジョン・廃坑・遺跡）と、魔術師系の敵から手に入ります。

## 探しに行くところ

危険度は低め。

| どこ | 何がある |
| --- | --- |
| 地上 | 酒場、見張り塔、井戸、廃墟、願いの井戸、灯台、商人のキャンプ、キノコの家 |
| 地下 | モンスター部屋、クモの洞窟 |
| 村 | 祭司の家（祭司は聖の魔術を使う） |
| 生き物 | グロットル（洞窟。ダイヤを背負った岩の生き物）、フォリアス（ジャングルの人食い植物）、ランタン（夜の森） |

## 冒険手帳

- [ ] ベッドで寝床を確保した
- [ ] 転移石に1つ以上触れた
- [ ] 酒場を見つけた
- [ ] リュックを作った
- [ ] 銘刻台を作り、魔導書に魔術を1つ書き込んだ
- [ ] 称号付き装備（名前の色が違う装備）を拾い、Ctrl＋T で安全地帯を有効化した
- [ ] 防具4部位と武器を、すべて称号付きにした（→「冒険」が開く）

> 【次の章へ】Ctrl＋T で「冒険」を有効化。ここから侵略者が現れ始めます。
