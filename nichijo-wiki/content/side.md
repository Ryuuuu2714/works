# 寄り道（釣り・リュック・家具）

## 釣り

```順番
鉄の釣竿 → 金 → ダイヤ → ネプツニウム
```

- 針や浮きで性能が変わる
- 魚はフィレナイフでさばくと食料になる。魚拓を額に飾ることもできる
- 海の宝物から [[ネプツニウムインゴット]] が出れば、強い武器・防具・釣竿が作れる。戦いが苦手な人の、もうひとつの成長ルート

## リュック

```順番
[[革のリュック]] → 銅 → 鉄 → 金 → ダイヤ → ネザライト
```

「自動で拾う」「磁石」「自動で食べる」「かまど」などの機能を後付けできます。図鑑で「機能」と検索すると一覧が出ます。

## 家具

椅子・机・棚・ベッド・飾り皿など、拠点を暮らせる場所にする家具がそろっています。
図鑑の絞り込みで「Handcrafted」を選ぶと一覧が出ます。

## 拠点の名前

転移石・町・道の名前は、みんなで決めて [世界の成り立ち](lore.md) に書き足していきましょう。
