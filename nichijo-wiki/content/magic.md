# 魔術のしくみ（Iron's Spells）

## 呪文の手に入れ方

1. [[スクロール]] を手に入れる（宝箱・魔術師から／[[スクロールフォージ]] で作る）
2. [[銘刻台]] で、魔導書に書き込む
3. 魔導書を装備画面の「魔導書のスロット」に入れて唱える

魔導書から取り出すと、その呪文の書き込みは消えます。スクロールをそのまま使うと、1回だけ唱えられて消えます。

## 魔導書の段階

| 段階 | 魔導書 | 主な材料 |
| --- | --- | --- |
| 1 | [[鉄縛の書]] | 鎖・革・紙 |
| 2 | [[見習いの魔法書]] | 金インゴット・[[秘術のエッセンス]]・[[ホグリンの革]] |
| 3 | [[エンチャントされた魔法書]] | ダイヤ・エンチャントの本・[[秘術の布]]・[[ホグリンの革]] |
| 4 | [[古代の写本]]／[[終龍の魔法書]] など | [[ボロボロの本]]、[[龍の革]] など |

段階が上がるほど、書き込める呪文の数が増えます。

## 9つの系統とフォーカス

[[スクロールフォージ]] では、系統の象徴となる素材（フォーカス）で、作るスクロールの系統が決まります。

| 系統 | フォーカス | 得意なこと |
| --- | --- | --- |
| 炎 | ブレイズロッド | 直接ダメージと燃焼 |
| 氷 | [[凍った骨]] | ダメージと足止め |
| 雷 | [[雷入りの瓶]] | 集中ダメージ |
| 聖 | [[ディバインパール]] | 回復・味方の強化 |
| エンダー | エンダーパール | 謎・移動・何でも屋 |
| 血 | [[血液瓶]] | 自分を強化・回復する攻撃 |
| 召喚 | エメラルド | 召喚・幅広い補助 |
| 自然 | 青くなったジャガイモ | 弱体化 |
| エルドリッチ | 反響の欠片 | 古代の禁じられた系統。世界に散らばる「異界の写本」の断片を集めて復元すると習得できる |

## インクの等級

コモン → アンコモン → レア → エピック → レジェンダリー。
インクの等級で、作れるスクロールの強さが決まります。上位のインクは、魔法の宝箱や、魔術を使う敵から。
いらないスクロールは、[[錬金術師の大釜]] で溶かしてインクに戻せます。

## 防具の段階

1. 放浪の魔術師（革の防具＋[[秘術のエッセンス]]）→ [[放浪の魔術師のローブ]]
2. 系統の魔術師の防具（[[秘術の布]] の防具＋系統のルーン＋[[秘術のエッセンス]]）
3. アップグレード（[[秘術の金床]]。アップグレードオーブは [[ミスリル鉱石]] から取れるミスリル・[[燃え殻のエッセンス]]・[[秘術のインゴット]] から）

## 地図とコンパス

- [[わがままなコンパス]]：カタコンベ（不死者の帝王）を指す
- [[巻かれた地図]]：特定の構造物への道を記した地図。城塞の地図（[[燃え殻のエッセンス]]・[[古代の知識の断片]]・紙）や、氷蜘蛛の巣の地図（[[凍った骨]]・クモの巣・[[秘術の布]]）を作れるほか、遺跡の中で見つかることもある。
