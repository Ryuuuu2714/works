# 魔術のしくみ

Iron's Spells の魔術のまとめです。

## 魔術を使うまで

```順番
[[スクロール]] を手に入れる → [[銘刻台]] で魔導書に書き込む → 魔導書を「魔導書のスロット」に入れて唱える
```

- スクロールは、宝箱・魔術師から手に入るほか、[[スクロールフォージ]] で作れる（下の「奥義」はのぞく）
- スクロールをそのまま使うと、1回唱えて消える
- 魔導書から取り出すと、その魔術の書き込みは消える

## 魔導書の段階

| 段階 | 魔導書 | 主な材料 |
| --- | --- | --- |
| 1 | [[鉄縛の書]] | 鎖・革・紙 |
| 2 | [[見習いの魔法書]] | 金インゴット・[[秘術のエッセンス]]・[[ホグリンの革]] |
| 3 | [[エンチャントされた魔法書]] | ダイヤ・エンチャントの本・[[秘術の布]]・[[ホグリンの革]] |
| 4 | [[古代の写本]]、[[終龍の魔法書]] など | [[ボロボロの本]]、[[龍の革]] など |

段階が上がるほど、書き込める魔術の数が増えます。

## 名前付きの魔導書

拾うと最初から魔術が入っている魔導書です。魔術は書き換えられませんが、[[秘術の金床]] で強くできます。

| 魔導書 | 手に入れ方 |
| --- | --- |
| [[朽ち果てた魔導書]] | 腐敗した場所の宝箱 |
| [[村人の教典]] | アーキヴォーカーに捕まった村人を助ける |
| [[煉獄のマニュアル]] | ブレイズ |
| [[召喚のグリモア]] | エヴォーカー・アーキヴォーカー |
| [[ネクロノミコン]] | 不死者の帝王 |

## 9つの系統

[[スクロールフォージ]] では、フォーカス（系統の素材）で、作るスクロールの系統が決まります。

| 系統 | フォーカス | 得意なこと |
| --- | --- | --- |
| 炎 | ブレイズロッド | 直接ダメージと燃焼 |
| 氷 | [[凍った骨]] | ダメージと足止め |
| 雷 | [[雷入りの瓶]] | 集中ダメージ |
| 聖 | [[ディバインパール]] | 回復・味方の強化 |
| エンダー | エンダーパール | 移動・何でも屋 |
| 血 | [[血液瓶]] | 自分を強化・回復する攻撃 |
| 召喚 | エメラルド | 召喚・幅広い補助 |
| 自然 | 青くなったジャガイモ | 弱体化 |
| エルドリッチ | 反響の欠片 | 古代の禁じられた系統。世界に散らばる「異界の写本」の断片を集めて復元すると習得できる |

## 奥義

各系統を代表する強い魔術は「奥義」として、[[スクロールフォージ]] では作れません。
大災厄を倒すたびに、その系統の奥義のスクロールが1枚出ます。

| 系統 | 奥義 | 落とす大災厄 |
| --- | --- | --- |
| 炎 | ファイヤーボール | イグニス |
| 雷 | ライトニングボルト | スキュラ |
| 氷 | ブリザード | リヴァイアサン |
| 聖 | グレートヒール | マレディクタス |
| 血 | ハートストップ | 古の魔獣の骸 |
| 自然 | 地震 | ネザライトの怪物 |
| 召喚 | ヴェックス召喚 | ハービンジャー |
| エンダー | ブラックホール | エンダーガーディアン |

- スクロールは1枚で1人分です。欲しい人の数だけ挑み直してください。大災厄はどれも、同じ場所でもう一度呼べます（→ [第三章](ch3.md)）。
- 出るスクロールのレベルは毎回ちがいます。同じ奥義のスクロールを2枚、[[秘術の金床]] で重ねると、レベルが上がります。
- 宝箱や魔術師から、ごくまれに出ることもあります。

> 【メモ】ヘルレイズ（炎）とファングスワール（召喚）も、もとから作れない魔術です。ヘルレイズは城塞の宝物庫、ファングスワールは不吉な不死者の帝王から手に入ります。

## インクの等級

```順番
コモン → アンコモン → レア → エピック → レジェンダリー
```

インクの等級で、作れるスクロールの強さが決まります。上位のインクは、カタコンベや城塞の宝物庫などの宝箱と、魔術を使う敵から。
いらないスクロールは、[[錬金術師の大釜]] で溶かしてインクに戻せます。

## 防具の段階

```順番
放浪の魔術師の防具 → 系統の魔術師の防具 → [[秘術の金床]] でアップグレード
```

| 段階 | 材料 |
| --- | --- |
| 放浪の魔術師（[[放浪の魔術師のローブ]] など） | 革の防具＋[[秘術のエッセンス]] |
| 系統の魔術師 | [[秘術の布]] の防具＋系統のルーン＋[[秘術のエッセンス]] |
| アップグレード | アップグレードオーブ（[[ミスリル鉱石]] のミスリル・[[燃え殻のエッセンス]]・[[秘術のインゴット]] から） |
