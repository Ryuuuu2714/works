# 参加のしかた

日常鯖は、Prism Launcher という起動ソフトで遊びます。  
最初の準備は1回のみでだいたい15分くらいで終わります。  
それ以降のMOD追加や更新は、起動のたびに自動で入るので、特に何もしなくて大丈夫です。

## 用意するもの

- Windows のパソコン（実装RAM 最低でも8GB以上）
- Microsoft アカウント（いつもマイクラに使っているもの）
- 東野から Discord で受け取る **Nichijo.zip**（このWikiには置いていません）

## 手順

1. [Prism Launcher の公式サイト](https://prismlauncher.org/download/windows/) から Windows 版を入れる。
2. 初回の設定で、Java の「自動ダウンロード」をオンにし、Microsoft アカウントでログインする。
3. Prism の「起動構成を追加」→ 左の「インポート」→「参照」でダウンロードした Nichijo.zip を選び、「OK」。
4. 一覧にできた「Nichijo」を選んで「起動」。
5. 初回は、Java・マイクラ本体・NeoForge と、60個近くのMODをダウンロードするので結構かかります。くれぐれも Launcher を閉じないように待っていてください。
6. しばらくするとタイトル画面が開くので、言語、音量やマウス感度などあらかた設定をいじった後「マルチプレイ」に登録されている「日常鯖」に接続します。
7. めちゃくちゃカクつくとか、なにかしらの不具合が起きてなければ参加完了！！

> 【注意】日常鯖に参加したかったら、必ず **Prism の「Nichijo」から起動してください**。  いつものランチャー（クリーパーアイコンのやつ）からはMODが導入できないので参加できません。
> 
> 【注意】MODを勝手に自分で足したり消したりしないでください。  入れたいものがあれば、まずは東野に相談してネ  （とはいえ影MODとかはクライアントオンリーのMODなので、自分のPCスペックと相談しながらなら好きに入れてもらってOK）。

## メモリの設定

マイクラの描画処理などに使うクライアント側の最大メモリは6GBにしてあります。  パソコンのメモリが8GBの人は、Prism で「Nichijo」を右クリック →「編集」→「設定」→「Java」で、最大メモリを **4096** に下げてください。

## うまくいかないとき

- 入れない：鯖落ちやメンテナンスなど何かしらの原因でサーバーが開いてないかもしれません。Discordの「サーバー通知」に連絡が無いか確認してください。
- 起動しない・すぐ落ちる：「Nichijo」を右クリック →「フォルダーを開く」→ `logs` の中の `latest.log` を東野に送ってください。
- 重い：ゲーム内の「ビデオ設定」で描画距離・演算距離などを下げる。ブラウザなど、できるだけ他のソフトを閉じる。
