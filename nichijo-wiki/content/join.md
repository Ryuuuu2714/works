# 参加のしかた

日常鯖は、Prism Launcher という起動ソフトで遊びます。最初の準備は1回だけ、15分くらいです。
MODの追加や更新は、起動のたびに自動で入るので、そのあとは何もしなくて大丈夫です。

## 用意するもの

- Windows のパソコン（メモリ8GB以上）
- Microsoft アカウント（いつもマイクラに使っているもの）
- 東野から Discord で受け取る **Nichijo.zip**（このWikiには置いていません）

## 手順

1. [Prism Launcher の公式サイト](https://prismlauncher.org/download/windows/) から Windows 版を入れる。
2. 初回の設定で、Java の「自動ダウンロード」をオンにし、Microsoft アカウントでログインする。
3. Prism の「インスタンスを追加」→ 左の「インポート」→「参照」で Nichijo.zip を選び、「OK」。
4. 一覧にできた「Nichijo」を選んで「起動」。
5. 初回は、Java・マイクラ本体・NeoForge と、約50個のMODのダウンロードで数分かかります。小さな窓が消えるまで待ちます。
6. タイトル画面の「マルチプレイ」に「日常鯖」が登録されているので、接続します。

> 【注意】必ず Prism の「Nichijo」から起動してください。いつものランチャーからはMODが入らず、入れません。

> 【注意】MODを自分で足したり消したりしないでください。入れたいものがあれば、東野に相談を。

## メモリの設定

最大メモリは6GBにしてあります。パソコンのメモリが8GBの人は、Prism で「Nichijo」を右クリック →「編集」→「設定」→「Java」で、最大メモリを **4096** に下げてください。

## うまくいかないとき

- 入れない：ホワイトリストに入っていないかもしれません。マイクラのIDを東野に伝えてください。
- 起動しない・すぐ落ちる：「Nichijo」を右クリック →「フォルダーを開く」→ `logs` の中の `latest.log` を東野に送ってください。
- 重い：ゲーム内の「ビデオ設定」で描画距離を下げる。ブラウザなど、ほかのソフトを閉じる。
