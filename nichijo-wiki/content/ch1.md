# 第一章　辺境をひらく

```概要
位階: 冒険
目標: 魔術師の塔や地下の遺構を巡って力をつけ、侵略者を初めて倒す
次へ進む条件: アンコモン以上の装備一式＋侵略者を倒す
```

## 新しく出てくる敵

| 敵 | 特徴 |
| --- | --- |
| 侵略者 | 大きな音・通知・空からの光の柱が合図。名前の色がレアリティ。倒すと強い称号付き装備を必ず落とす |
| 檻の中の侵略者 | 地下のダンジョンにいる。近づくと檻が開いて襲ってくる |
| エリート | 名前付きの強化された敵。称号付き装備を落とすことがある |
| 残忍なスポナー | 地下。強い敵を出す |
| 大群のスポナー | 地下。クモを大量に出す |

## 探しに行くところ

危険度は中くらい。

### 魔術師の住処

| 場所 | 住人・目当て |
| --- | --- |
| 紅蓮術師の塔 | 炎の魔術師 |
| 山の塔 | 氷魔術師。[[巻かれた地図]] があることも |
| マングローブの小屋 | 薬剤師 |
| エヴォーカー砦 | 大魔術師アーキヴォーカー。[[召喚のルーン]] を落とすことがある。捕まっている村人・行商人とは取引できる（→ [魔術のしくみ](magic.md)） |
| 氷蜘蛛の巣 | 寒い土地にある |

> 【注意】魔術師は、宝箱を荒らされると怒ります。

系統のルーンは、[[空白のルーンストーン]]（遺跡の宝箱から）のまわりに、その系統のフォーカスを8個並べて作れます。
紅蓮術師・氷魔術師・薬剤師は、取引でその系統のルーンを譲ってくれます（紅蓮術師は [[鎖で封じた本]] 4冊、氷魔術師は [[氷の牙]] 2個、薬剤師は強力なエリクサー4本と交換）。

### 地下

- 骸骨の要塞、ゾンビの地下墓地（第二章の「カタコンベ」とは別の場所）
- 騎士の間（Y=20〜50）：造られた騎士フェラスが眠る。倒すと [[千鋼の斧]] と [[ロートヘルム]]

### 地上の大型遺構

山賊の村・山賊の塔、イリジャーのキャンプ・風車、小型飛行船

### 試練の祠

陸地のあちこちにある、1〜5段階の腕試し。まずは1〜2段階から。

### 酒場のクエスト地図

酒場の地図屋から、エメラルド14個とコンパスで買える地図。行き先は地図ごとにちがいます。

- 毒の巣：クモの女王（中ボス）

## 冒険手帳

- [ ] 放浪の魔術師の防具をそろえた
- [ ] エンチャント台をLv30まで上げた
- [ ] 魔術師の塔を1つ攻略した
- [ ] 系統のルーンを1つ手に入れた
- [ ] 造られた騎士フェラスを倒した
- [ ] 試練の祠を1つ突破した
- [ ] アンコモン以上の装備一式を身につけた
- [ ] 侵略者を倒した（→「進撃」が開く）

> 【次の章へ】ネザーゲートの準備を。黒曜石・火打石・十分な食料。
