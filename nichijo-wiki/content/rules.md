# この鯖のルール

ほかの鯖やいつものマイクラと違うところを、まとめています。

## 移動は「自分の足」と「転移石」

この鯖には、ミニマップも全体地図もありません。新しい土地は、自分の目で見て、歩いて確かめます。
F3 で座標が見られるので、大事な場所は座標をメモするか、拠点に地図を飾っておきましょう。

ファストトラベルは、ウェイストーン（図鑑では [[転移ポイント]]）だけです。

| 決まり | 内容 |
| --- | --- |
| 飛べる先 | 一度その石に触れた（右クリックした）場所だけ |
| 飛び方 | 石から石へ。インベントリのボタンや [[ワープストーン]] では飛べない |
| 支払い | [[ワープダスト]]。250ブロックごとに1個（最低1個・最大8個） |
| 拠点へ帰る | 共有の拠点（グローバル設定の石）宛ては無料 |
| 待ち時間 | 一度飛ぶと、5分間は次に飛べない |
| 別の次元 | ネザーやエンドなどへは飛べない |
| ワーププレート | 拠点の中の短距離移動用。無料・待ち時間なし |

[[ワープダスト]] は、[[エンダーパール|minecraft:ender_pearl]] とアメジストの欠片から4個作れます。

### 魔術での移動

- Iron's Spells の「リコール」（スポーン地点＝ベッドへ帰る）や、短い距離のテレポート系の呪文は使えます。
- 「ポータル」の呪文も使えます。ふつうに唱えると、数分で消える2点間の門ができます。建築や運搬に便利です。
- 終盤の素材で作る [[ポータル境界]] に唱えると、消えない2点間の門になります。拠点と鉱山を結ぶような、自分たち専用の通路に。

## 死んでも持ち物は消えない

死んだ場所に「死体」が残ります。開けて持ち物を取り返しましょう。
仲間の死体を、代わりに回収してあげることもできます。

## 宝箱は人ごとに別々

宝箱の中身は、開けた人ごとに別々に用意されます（Lootr）。先に開けた人に取られることはありません。
宝箱は壊さずに、そのまま開けてください。

## そのほかの決まり

- 難易度はノーマル。
- スポーン地点の周りでも、ブロックを壊したり置いたりできます。
- 友人はOPではありません（コマンドやゲームモードの切り替えはできません）。
- 夜は、入っている人の半分が寝れば朝になります。
- 木は根元を斧で切ると丸ごと倒れます（しゃがむと1ブロックずつ）。
- 毎日 深夜4:00〜4:15ごろ、バックアップと再起動で数分止まります。
- MABで遊ぶ日は、日常鯖が止まります。起動・停止のお知らせは Discord に届きます。
- 新しい人を呼ぶときは、先にマイクラのIDを東野に伝えてください（ホワイトリスト）。
