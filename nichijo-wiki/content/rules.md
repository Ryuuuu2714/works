# この鯖のルール

このサーバーは かえるこうはい の希望MODを原案として、世界観を保つように東野が見繕ったMODをかなり大量に入れています。  
つまり「本来はこれを作ってから始める」「最初はここに行くべき」という各MODの定石が入り乱れていて、何から手を付けていいのか分からなくなり、なかなか遊び始めるハードルが高いです。  
  
ということで、MODそれぞれのシナリオ・攻略の流れを無理やり解釈して「**まるで一つの統合されたストーリーをなぞってプレイする**」ようにプレイできるようこのWikiを作りました。  
（ちょっと世界観設定が厨二病っぽいけど…なんとなく話の流れがあったほうが関連付けて何をすべきか覚えやすいと思うので。）  
  
以下には、いつものマイクラと違うところをまとめています。

## 長距離移動は「転移石」

この鯖は、長期的な運用 + 各地での街や文明の発展 を見込んでるので遊んでいくにつれて移動が大変になっていきます。（ミニマップMODや全体地図MODは諸事情で消しました。）  
かといって、せっかく魔術を学ぶ世界なのにポンポンと気軽にテレポートできるのは癪なので、この鯖では**コストを支払うことで「ファストトラベル」ができます！**  
ファストトラベルは、[[転移石]]（ウェイストーン）という石柱のようなオブジェクトで利用可能です。

| 決まり | 内容 |
| --- | --- |
| 転移先 | 一度その転移石に触れた（右クリックした）場所 |
| 飛び方 | 転移石から転移石へ。 |
| コスト | [[ワープダスト]]というアイテムを250ブロックごとに1個（最低1個・最大8個）消費する |
| 拠点へ帰る | 共有の拠点（グローバル設定の転移石）に帰るときだけは無料！ |
| 待ち時間 | 一度飛ぶと、5分間のクールダウン |
| 別の次元 | ネザーやエンドなどへは飛べない |

[[ワープダスト]] は、[[エンダーパール|minecraft:ender_pearl]] とアメジストの欠片から4個クラフトできます。

### 魔術での移動

- 「リコール」という魔術（スポーン地点＝ベッドへ帰れる）や、短距離テレポート系の魔術は普通にマナ消費などで使えます。
- 「ポータル」の魔術も使えます。これは数分で消える2点間の門を作る魔術で、大規模建築や資源運搬などで使うんじゃないかな～とか思ってます。
- 終盤の素材で作る [[ポータル境界]] に「ポータル」の魔術を唱えると、消えない2点間の門になります。拠点とどこか好きな場所を結ぶプライベート通路として使えます。

## 死んでも持ち物は消えない

死んだ場所に「死体」が残ります。開けて持ち物を取り返しましょう。  
仲間の死体を、代わりに回収してあげることもできます。  
（死体は1時間くらいで白骨化しますが、確か問題なくアイテム回収できたはずです）

## 宝箱は人ごとに別々

MODによって宝箱の中身は、開けた人ごとに別々に用意されます。  
先に開けた人にレアアイテムを取られることはなく、完全に自分の運との戦いです。  
（上記に関連して、プレイヤーごとの宝箱の中身は「**宝箱を開けた瞬間に生成**」してるので、開ける前にぶっ壊すと消失します。特に変なことせずそのまま開けてください）。

## そのほかの決まり

- 難易度はノーマル。
- 夜は、入っている人の半分が寝れば朝になります。
- 木は根元を斧で切ると丸ごと倒れます（しゃがむと1ブロックずつ）。
- 毎日 深夜4:12ごろに再起動します（1分前にチャットで予告。止まるのは1分足らず）。4:00のバックアップ中は止まりません。OSの更新があった日は、4:30ごろにもう一度数分止まることがあります。
- MABで遊ぶ日は、日常鯖が止まります（というか同時開放ができないので一方が開いてると他方は閉まってるという認識でヨロ）。起動・停止のお知らせは Discord に届きます。
