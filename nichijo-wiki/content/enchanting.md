# エンチャント台（Apothic Enchanting）

この鯖のエンチャント台は、Lv100まで上がります。
本棚の種類で「エテルナ（強さ）」「クアンタ（ぶれ）」「アルカナ（珍しさ）」などが変わります。
むずかしく考えず、「高いほど良い」で大丈夫です。

## 段階

| レベル | 必要なもの |
| --- | --- |
| 〜30 | 普通の本棚15個 |
| 45〜60 | [[地獄の本棚]]（ネザー）か [[海の本棚]]（海）。「注入エンチャント」で本棚そのものを強化する（例：[[注入された地獄の本棚]]） |
| 70〜80 | [[深淵の本棚]] → ディープダークの素材（反響の欠片・スカルク）→ ウォーデンを倒してスカルクの本棚 |
| 90〜100 | ドラゴンブレスを注入したエンドの本棚、竜の頭から竜のエンドの本棚 |

注入エンチャントは、エンチャント台に材料を置いて、必要な属性値を満たすと起きる特別なエンチャントです。
図鑑でその本棚を開くと、必要な属性値が分かります。

## エンチャントの貯金

[[エンチャント書庫]] にエンチャントの本を放り込むと、エンチャントを貯めておけます。
必要なレベルだけ取り出せます。上位は [[アレクサンドリア書庫]]。

## 世界の位階との関係

位階によって、エンチャントの上限などが変わることがあります。Ctrl＋T の画面の「詳細情報」で確かめられます。
