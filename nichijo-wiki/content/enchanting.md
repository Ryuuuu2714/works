# エンチャント台

エンチャントは、帝国の鍛冶と、工房の都の「魔力を練りこむ」技から生まれた技術です（→ [世界の成り立ち](lore.md)）。

Apothic Enchanting で、エンチャント台は Lv100 まで上がります。
本棚の種類で「エテルナ（上限）」「クアンタ（ぶれ）」「アルカナ（珍しさ）」などの値が変わります。まずは「高いほど良い」と覚えれば十分です。

## 段階

```順番
Lv30 普通の本棚 → Lv60 地獄・海の本棚 → Lv80 深淵・スカルクの本棚 → Lv100 エンドの本棚
```

| レベル | 必要なもの |
| --- | --- |
| 〜30 | 普通の本棚15個 |
| 45〜60 | [[地獄の本棚]]（ネザー）か [[海の本棚]]（海）。注入エンチャントで本棚そのものを強化する（例：[[注入された地獄の本棚]]） |
| 70〜80 | [[深淵の本棚]] → ディープダークの素材（残響の欠片・スカルク）→ ウォーデンを倒してスカルクの本棚 |
| 90〜100 | ドラゴンブレスを注入したエンドの本棚、ドラゴンの頭から竜宿るエンドの本棚 |

> 【メモ】注入エンチャントは、エンチャント台に材料を置いて、必要な値を満たすと起きる特別なエンチャントです。図鑑でその本棚を開くと、必要な値が分かります。

## エンチャントの貯金

[[エンチャント書庫]] にエンチャントの本を入れると、エンチャントを貯めておけます。
必要なレベルだけ取り出せます。上位は [[アレクサンドリア書庫]]。

## 位階との関係

位階によって、エテルナの上限などが変わります。Ctrl＋T の画面の「詳細な情報」で確かめられます。
